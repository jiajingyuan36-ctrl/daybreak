## 代码改了哪里

1. **每页独立的链接预览（Open Graph）和 canonical**
   - 问题：以前所有页面的 `og:title`、`og:description`、`og:url` 都是首页的。在微信、小红书里转发星座页或抽牌页，预览显示“晨启塔罗 · 每天早上抽一张塔罗”，链接也指回首页。今日塔罗、回望、设置、牌阵四页连自己的标题都没有。
   - 改法：新增 `src/meta.ts` 的 `pageMeta()`，`app/` 下 12 个页面都改用它；每页有自己的标题、描述、`og:url` 和 canonical。预览图仍共用 `/og.png`。
2. **首页首屏提速**：`app/page.tsx` 预加载日历专用的那半套中文字体。模拟 4G + 手机 CPU：首次内容绘制约 1.56 秒 → 0.85 秒，最大内容绘制约 3.5 秒 → 2.75 秒。抽牌页约 2.0 秒、星座页约 1.0 秒，没改。三页在 iPhone 尺寸下都没有横向溢出。
3. **批量封面脚本** `scripts/xhs-covers.mjs`（`npm run covers`）
   - 读 `content-kit/covers.json`，输出 1080×1440 JPG（加 `--png` 输出 PNG）。
   - 夜版（曜石黑 + 香槟金）和晨版（羊皮纸 + 古铜）两种，用网站同款衬线字体和 1909 原版牌面，1–3 张牌。
   - 字体里没有的字会提示，并用思源黑体代替。
4. `package.json` 只加了一行 `"covers"` 脚本，**没有新增依赖**。

网站原有的“今日一张牌”分享图（4:5 和 9:16）没有改；要不要加 3:4 见 待确认.md 第 16 条。

**验证**：`npm run typecheck` 通过，`npm test` 68 项全部通过，`npm run build` 成功。在构建产物上用模拟 iPhone 完整抽了一次牌，三种切牌手势都正常。

## 怎么在本地预览

```bash
cd daybreak
git checkout content-kit
npm ci

# 看网站
npm run dev                         # http://localhost:3000
# 或者看生产构建
npm run build && npx serve dist     # 也可以：cd dist && python3 -m http.server 4173

# 检查链接预览：打开 dist/zodiac/index.html，搜 og:title，应该是“十二星座与塔罗 · 晨启塔罗”

# 重新生成封面（第一次需要装 Playwright，--no-save 不会改 package.json）
npm i --no-save playwright && npx playwright install chromium
npm run covers                      # 输出到 content-kit/covers/
```

Markdown 文档可以直接在 GitHub 网页或手机 GitHub App 里看。
