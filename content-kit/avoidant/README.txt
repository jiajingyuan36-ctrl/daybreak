《回避型依恋》A24 电影胶片风短视频 — 完整素材与 Claude Code 制作包
====================================================================

包含文件：
1. images/bg_1.jpg ~ bg_5.jpg   : 5 张统一 A24 35mm 胶片色调 9:16 高清电影底图
2. CLAUDE_CODE_MASTER_PROMPT.md : 详尽到每一幕动效与卡点的 Claude Code 完整指令
3. script_and_captions.json     : 结构化口播稿、字幕高亮词、以及抖音发布标题与置顶评论

三步直接出片：
Step 1: 将 images/ 里的 bg_1.jpg ~ bg_5.jpg 全部复制到你 Remotion 项目的 public/images/ 目录下（覆盖旧图）。
Step 2: 把 CLAUDE_CODE_MASTER_PROMPT.md 里的全部内容直接复制发给 Claude Code。
Step 3: 跑完配音后在 Remotion Studio 预览，确认无误直接运行 npx remotion render 导出，发抖音时配一首极简钢琴/雨夜纯音乐（音量 12%~15%）即可。
