## 一、全局视觉规范：「A24 35mm 电影胶片静帧 + 极简情绪独白」

### 1. 配色与光影纪律（彻底去 AI 味、拒绝死黑）
- **严禁**：荧光霓虹色、白色硬阴影卡片、荧光黄底涂抹、厚重黑底字幕条、廉价表单绿按钮、或任何赛博仪表盘装饰。
- **底图通透度**：每一幕使用 `<Img src={staticFile('images/bg_X.jpg')} />` 全屏铺满（`objectFit: 'cover'`）。全局暗遮罩严格控制在 **`rgba(0, 0, 0, 0.32)` ~ `rgba(0, 0, 0, 0.38)`**，绝不要压成死黑一团！只在顶部 `22%` 与底部 `32%` 叠加柔和线性暗角渐变，保证电影光影和窗外光斑清晰透出，同时文字高对比易读。
- **35mm 胶片质感层（`FilmOverlay.tsx`）**：
  - 全屏叠加极轻 SVG `feTurbulence` 胶片颗粒（`opacity: 0.04`，每 3 帧微微变换 `seed` 模拟真实胶片呼吸感）。
  - 左上角极克制细等宽字标注：`EP.02 · AVOIDANT ATTACHMENT`（`rgba(243, 239, 230, 0.45)`，字号 `20px`，避开顶部 `180px` 安全区）。
- **配色系统**：
  - 主字色（暖胶片白）：`#F3EFE6`（搭配 `textShadow: '0 2px 16px rgba(0,0,0,0.65)'`）。
  - 核心情绪高亮色（低饱和琥珀金）：`#E5C585`。
  - 警示/划掉色（克制哑光暗红）：`#C84B4B`（零霓虹发光）。
  - 辅助说明色：`rgba(243, 239, 230, 0.62)`。
- **字体系统**：
  - 核心大字与金句强制使用**中粗宋体衬线体**：`'Songti SC', 'Noto Serif SC', 'STSong', 'Georgia', serif`，字距 `0.06em`~`0.1em`。
  - 微信模拟消息与小标签使用无衬线体：`'-apple-system', 'PingFang SC', 'Helvetica Neue', sans-serif`。
- **动效与转场纪律**：
  - 底图全程缓慢电影推镜（Ken Burns：`scale(1.0 -> 1.07)` + 极轻微水平/垂直平移）。
  - 核心大字使用温柔的**焦外模糊聚焦**（`filter: blur(10px) -> blur(0px)` + `opacity: 0 -> 1` + `translateY(14px -> 0)`）。
  - 幕与幕之间使用 **12 帧平滑交叉溶图（Cross-dissolve）**，保持电影呼吸感。

### 2. 抖音竖屏安全区与底部电影字幕（`CinemaSubtitle.tsx`）
- **安全区**：所有核心视觉与字幕严格避开**顶部 `180px`、右侧 `140px`、底部 `280px`**。
- **字幕样式**：位于 `bottom: 310px` 居中处，**不要厚重纯黑圆角底框**！采用纯正电影字幕风：`38px` 暖白粗体 `#F3EFE6`，配合柔和多层暗影保证在任何亮部都清晰；每一句中的核心情绪词用琥珀金 `#E5C585` 点亮。按每句字数/停顿精准切分，单行不超过 14 个汉字，严禁长段落堆砌。

## 二、Fish Audio 配音与时间轴自动同步规范

1. 在 `src/avoidant-script.ts` 中存入下方 5 幕精确口播文案（已规避所有容易被 TTS 念错的生僻多音字，总时长控制在 **38~44 秒**，最适合抖音冷启动高完播）。
2. 在配音生成脚本中调用 Fish Audio API（`POST https://api.fish.audio/v1/tts`）：
   - `reference_id`: `"159b7a7b9a8b4a27b21f6d32111718a6"`（电影解说男声）
   - `format`: `"mp3"`, `mp3_bitrate`: `192`, `temperature`: `0.7`, `top_p`: `0.7`
   - **分幕动态语速控制**（极其关键，决定前 5 秒留存与结尾后劲）：
     - Scene 1: `prosody.speed: 1.08`（开场干脆抓人）
     - Scene 2 ~ 4: `prosody.speed: 1.05`（紧凑流畅不拖沓）
     - Scene 5: `prosody.speed: 0.98`（收尾放缓留出情绪后劲）
   - 输出至 `public/audio/avoid_1.mp3` ~ `public/audio/avoid_5.mp3`。
3. 用 `ffprobe` 自动读取 5 段音频的精确时长（秒），Scene 1~4 末尾各加 `0.2s` 短呼吸停顿，Scene 5 末尾加 `0.8s` 情绪留白，写入 `src/avoidant-timeline.json`。
4. 主 Composition（ID 命名为 `AvoidantAttachment`）严格读取 `src/avoidant-timeline.json` 计算总帧数与每幕 `<Sequence>` 起止帧。
5. 如果 `public/audio/bgm_piano.mp3` 存在，以 `volume={0.14}` 自动混入并在最后 2 秒平滑淡出至 `0`。
