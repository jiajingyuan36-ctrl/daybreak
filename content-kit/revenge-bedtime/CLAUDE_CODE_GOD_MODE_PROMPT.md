# 核心原则：如何发挥 Claude Code 的最大工程与审美能力（必须严格执行）

1. **先建引擎，再写分镜（拒绝面条代码）**：
   先搭建一套电影级可复用视觉与声效引擎，再编写 5 幕场景：
   - `src/design/tokens.ts`：全片色彩弧线、字体、安全区常量、电影缓动曲线（`EASE_CINEMA = Easing.bezier(0.16, 1, 0.3, 1)`、`EASE_SNAP = Easing.bezier(0.85, 0, 0.15, 1)`）。
   - `src/engine/CameraRig.tsx`：**2.5D 景深视差摄影机组件**（支持 Speed Ramp 变速推镜、3D 微倾斜 `perspective(1200px) rotateX/Y`、高潮帧 `cameraShake` 冲击抖动、以及 `RackFocus` 景深虚化切换——底图、中景信息图、前景漂浮微尘三层以不同视差速率运动）。
   - `src/engine/OpticalPolish.tsx`：**电影光学后期层**（35mm 呼吸颗粒噪点、柔和电影暗角、场景转场动态暖/冷漏光 Light Leak、以及在冲击帧触发 3 帧的极轻微 RGB 色散微效 Chromatic Aberration）。
   - `src/engine/KineticText.tsx`：**百万剪辑师级动力学文字组件**（焦外模糊聚焦 `blur(12px)->0`、逐词弹性弹出、精准 `<span>` 绑定手绘斜杠删除线、荧光/冷蓝微光扫过）。
   - `src/engine/CinemaSubtitle.tsx`：**抖音安全区电影字幕**（位于 `bottom: 305px`，严禁厚重黑框，采用多层柔和阴影 + 逐词情绪高亮，单行严格 <= 13 字）。
2. **100% 确定性渲染纪律（零闪烁、零渲染 Bug）**：
   - 所有动效必须 100% 由 `useCurrentFrame()`、`interpolate()`、`spring()` 驱动；**严禁**任何 CSS `transition`、`@keyframes` 或 `Math.random()`（所有粒子与颗粒必须使用 Remotion 内置 `random(seed)`）。
   - 所有百分比数值必须用 `Math.min(100, Math.max(0, Math.round(...)))` 严格封顶，严禁出现 `101%` 穿帮。
3. **程序化拟音音效工程（Procedural SFX Engine — 消灭“哑巴动画”）**：
   - 百万剪辑师 50% 的高级感来自**精准卡帧的微音效**！请编写一个 Node/Python 脚本 `scripts/generate-sfx.py`（仅使用标准库 `math`/`wave`/`struct` 或 `ffmpeg`，零外部付费依赖），程序化合成 6 个干净、克制、电影级拟音 WAV 文件到 `public/sfx/`：
     1. `impact_sub.wav`（0.45s 深沉低频 Sub-bass 冲击，用于痛点砸下、数字翻转）
     2. `whoosh_soft.wav`（0.35s 滤波白噪空气扫风声，用于卡片滑入与场景切换）
     3. `pop_glass.wav`（0.12s 清脆柔和的玻璃/气泡弹出声，用于微信/催命消息弹出）
     4. `tick_clock.wav`（0.08s 精密机械秒表滴答声，用于凌晨时钟跳变与刷视频计数）
     5. `alarm_harsh.wav`（0.90s 克制但刺耳的早八双频电子闹钟声，用于 Scene 4 惊醒硬切）
     6. `chime_warm.wav`（1.40s 温暖柔和的泛音钢琴和弦单音，用于 Scene 5 治愈转折）
   - 在 Remotion 中用 `<Audio>` 按**精确帧号**把对应拟音卡在每一次视觉冲击、消息弹出、删除线划过和硬切转场上（音量精细控制在 `0.18 ~ 0.35`，绝不盖过人声）。
4. **强制开启「自主抽帧视觉质检循环（Autonomous Visual QA Loop）」**：

# 三、执行与自检交付流程（一步都不能跳过）
