# 02 · 品牌文档草稿

> 依据网站现有文案（00-项目现状）和公开研究（01-研究）起草。**每一条都是我的猜测，标了“待Leo确认”**。文末有今晚的访谈题单。

## 1. 目标用户画像：林小满（待Leo确认）

- **23 岁**，在杭州做新媒体运营，工作第二年，和朋友合租。（待Leo确认：也可能更年轻——高中、大学生。网站里“学业”出现很多，经营者也是高中生，这是最大的不确定）
- 手机里装着小红书、网易云、一个记账 App；关注了几个星座号，但**取关过两个**，因为“老说下周有大事，吓人”。
- 不完全信塔罗，但**喜欢那种“被说中了一点点”的感觉**，更喜欢牌面本身好看。买过一副韦特塔罗，放在书架上没怎么用，因为“看不懂解释书”。
- 知道自己是白羊座，说不清上升星座。
- 对隐私敏感：讨厌“先注册再看结果”“扫码领取完整报告”。
- 会把好看的图存进相册，偶尔发朋友圈；在小红书上是收藏多、评论少。

### 她早上的状态和需求（待Leo确认）
- **7:40 闹钟**，赖床 5 分钟刷手机。这 5 分钟是晨启的窗口。
- 状态常常是“**还没开机**”：有点累、有点焦虑今天的会、昨晚睡得不好。
- 她要的不是“今天会发生什么”，而是：
  1. **一个开机按钮**：一个小小的仪式，让她从“被闹钟吵醒”变成“我开始今天了”。
  2. **一句被理解的话**：“今天可以慢一点”比“今天运势 85 分”有用。
  3. **一件马上能做的小事**：十分钟以内，做完会觉得今天没白过。
  4. **晚上能回头看一眼**：睡前想想早上那张牌说得对不对（网站已有“晚间回顾”）。
- 她**不需要**：长篇解读、复杂牌阵、付费咨询、恐吓。

## 2. 晨启和其他塔罗号的区别（待Leo确认）

| | 常见塔罗/星座号 | 晨启 |
| --- | --- | --- |
| 什么时候看 | 有事时、睡前、焦虑时 | **每天早上，开启一天** |
| 问什么 | “他会回来吗”“我能考上吗” | “**今天我可以怎么过**” |
| 给什么 | 预测、答案、运势分数 | **一句提醒 + 一件小事** |
| 怎么抽 | 博主替你抽、你选一组 | **你自己洗牌、切牌、选牌**（网站上真的要按住洗牌、划开切牌） |
| 牌 | 各种现代牌、AI 图 | **1909 年原版韦特塔罗**，标明出处 |
| 变现 | 引私信、付费解读 | 免费、不注册、不引导付费（待Leo确认，见待确认.md） |
| 语气 | 神秘、悬念、偶尔吓人 | **温和、口语、像朋友** |

**一句话定位（草稿）**：晨启是你每天早上的第一个小仪式——亲手抽一张 1909 年的原版塔罗，读一句大白话，做一件十分钟的小事。（待Leo确认）

## 3. 我们反对什么（待Leo确认）

1. **反对恐吓**：不说“大凶”“血光”“不看后悔”，不把逆位说成倒霉。
2. **反对替你做决定**：牌是镜子，不是判决书。重要的事听自己和专业的人。
3. **反对套路**：不先注册、不扫码领报告、不制造稀缺（“仅剩 3 个名额”）。
4. **反对玄乎**：不说“能量”“灵验”“开运”；讲画面、讲历史、讲出处。
5. **反对焦虑消费**：不卖转运商品，不用焦虑换付费。

## 4. 核心信念（待Leo确认）

1. **一天的开头值得被认真对待。** 哪怕只有一分钟。
2. **牌不预测未来，它帮你看见今天的自己。**
3. **小事比大道理有用。** 每张牌都落到一件十分钟能做完的事。
4. **好东西要有来处。** 1909 年原版牌面、Waite 原文、真实月相——写清楚出处。
5. **你的记录属于你。** 不注册，只存在你自己的手机里。

## 5. 语气规则（待Leo确认）

**像什么**：一个比你早起半小时、已经泡好茶的朋友，坐在你床边说两句话。

- **用“你”**，不用“宝子们”“家人们”“姐妹们”（待Leo确认：小红书常见称呼可能有助于亲近感，但和网站语气不一致）。
- **短句**：一句话不超过 25 个字；一段不超过 3 句。
- **先讲画面，再讲意思**：“画上的年轻人背着小包站在崖边”→“它说的是那种还没准备好、但很想试试的劲儿”。
- **给选择，不给结论**：“如果你最近……，可以试试……”；不用“一定”“必须”“注定”。
- **逆位说成“卡住了”**，不说成“坏”。
- **每条都落到一件小事**，并且具体（“把桌面上那个拖了三天的文件打开”而不是“提升效率”）。
- **可以有一点幽默**，但不嘲笑任何星座。
- **emoji 克制**：每段最多一个，用 🌙 ☀️ ✦ 🃏 这类，不用 💥 😱。
- **结尾固定一句**：“塔罗只是给今天一个提醒，不预测未来。”
- **禁用词**：见 01-研究 第三节表格（准到哭、必脱单、转运、改运、算命、私信我看……）。

## 6. 视觉延续（待Leo确认）

小红书封面沿用网站的两套：
- **夜版**：曜石黑底 + 香槟金细线 + 象牙白衬线字（适合星座科普、每日一牌）。
- **晨版**：羊皮纸底 + 深墨字 + 古铜细线（适合“早安”“晨间仪式”）。
牌面一律用 1909 原版 RWS 扫描（公有领域）。封面图脚本见 README。

1. 你做晨启的起点是什么？是你自己每天早上抽牌，还是看到别人有需要？

**关于定位和边界**

10. “深度解读”你打算怎么做？谁来解读、收不收费、监护人知道吗？
11. 你最喜欢、最不喜欢哪几个塔罗/星座号？为什么？

**关于内容**
12. 你更想做图文还是视频？有没有现成的牌、桌布、拍摄道具？

14. 账号名、头像、简介定了吗？想不想沿用“晨启塔罗 DAYBREAK”？
15. 有没有一句话，是你最希望用户看完晨启以后记住的？
