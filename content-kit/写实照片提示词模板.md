# 看不出是 AI 的照片：提示词怎么写（调研 + 模板，2026-11-25）

## 一、结论

真到看不出来的 AI 照片，几乎都靠同一个反直觉的做法：**不追求好看，追求「真实拍照时会发生的事」。**

- 引爆这股风潮的，是 Reddit 上一段故意写得很「敷衍」的提示词：要一张「极其普通的 iPhone 照片，没有主体、没有构图，带一点运动模糊，被不均匀的阳光照得有点过曝，角度尴尬，像从口袋里掏手机时误拍的」。爱范儿把它和真用 iPhone 7 拍的照片放在一起做竞猜，很多人分不出来（爱范儿 / 搜狐）。
- 为什么有效：模型的训练数据大多来自社交媒体和相册里的真实照片，里面满是手抖、过曝、构图乱。提示词描述这些「缺陷」，等于调用了模型见得最多的那一类真实照片（爱范儿的分析）。
- 反过来，「完美」「精致」「电影感」会把画面推向修过的宣传图，那正是一眼 AI 的来源（我们之前的调研）。

**所以写实分两条路**，先选一条：

| 路线 | 像什么 | 难度 | 用在哪 |
|---|---|---|---|
| **A. 随手拍** | 手机、卡片机、朋友抓拍 | 最容易以假乱真 | 生活感、旅行感、社交媒体风格 |
| **B. 专业纪实** | 摄影师用好相机拍的纪实人像、风景 | 更难，要靠光和细节 | 电影感、视频首帧（比如林栖） |

## 二、让照片「真」的六个来源

1. **说明设备和媒介**：iPhone、CCD 卡片机、35mm 胶片、开闪光灯。设备一出现，噪点、色彩、锐度、闪光灯的落差都跟着来了。
2. **写不完美**：轻微运动模糊、局部过曝、角度歪、构图随意、对焦没对准、闪光灯把前景打亮、背景发暗。
3. **写普通**：主体可以不在正中；画面里有杂物：电线、车角、垃圾桶、路人半个身子。
4. **光要有来源，物理要对**：同一个太阳下影子方向一致，反射对得上（专家鉴别 AI 图，看的正是影子、反射和透视；Hany Farid）。
5. **人要具体**：写清年龄、五官特点、发型、衣服、配饰。不写的话，模型给的是「平均脸」，大家撞脸（爱范儿实测）。
6. **删掉美化词，写上「不美化」**：OpenAI 官方示例写的是「诚实、不摆拍……不要美化，不要重度修图」。

## 三、模板

### 模板 A1：平凡无奇的 iPhone 随手拍（原版，英文效果最稳）

```
An extremely unremarkable iPhone photo with no clear subject or framing—just a careless snapshot. It includes [杂物：part of a sidewalk, the corner of a parked car, a hedge in the background]. The photo has a touch of motion blur, and is mildly overexposed from uneven sunlight. The angle is awkward, the composition nonexistent, and the overall effect is aggressively mediocre—like a photo taken by accident while pulling the phone out of a pocket.
```

### 模板 A2：随手拍 + 人物 + 地点（中文）

```
请生成一张极其平凡无奇的 iPhone 照片，像朋友随手拍的，没有刻意的构图。
主角：[年龄、性别、五官特点、发型、衣服、一个配饰]，正在[一个普通的动作]，没有看镜头。
地点和时间：[地点]，[时间]，旁边有[两三样杂物或路人]。
照片有一点运动模糊，[阳光不均导致局部过曝 / 室内光线偏暗有噪点]，角度有点歪，主体不在正中。
整体平平无奇，像是随手按下快门的生活照。不要美化，不要修图，不要磨皮，画面里不要有文字和水印。
```

### 模板 A3：CCD 卡片机 + 闪光灯（爱范儿总结的公式）

```
[人物描述]，穿着[服装]，[姿势/动作]，在[场景]，[光线描述]，背景里有[背景元素]，用[CCD 卡片机，例如 Sony DSC-W630 / Canon A650 IS]拍摄，开着闪光灯，人物被闪光灯打亮、清晰，背景偏暗、模糊，颗粒感，[色调]，像是[年份]拍的照片，随手抓拍，真实自然。
```

说明：写相机型号能带出那种年代感和闪光灯直打的效果。社区也提醒，写了设备名字，有的模型会把设备画进画面里（FLUX 社区经验），出现了就删掉型号，改写「卡片机闪光灯直打的质感」。

### 模板 B1：专业纪实人像（Google 官方三段式 + OpenAI 抓拍写法）

```
一张真实照片（photorealistic），[景别：胸像 / 半身 / 全身]，拍的是[人物描述]，[动作或表情：抓拍的一瞬间，不看镜头]，在[地点和环境]。
光：[唯一的光源和方向，例如「上午的阳光从画面右侧照来，脸上有清楚的明暗，阴影里看得见细节」]，整体是[情绪]的气氛。
拍摄：[焦段，例如 50mm]，[景深]，焦点在[眼睛]，突出[皮肤纹理、毛孔、碎发、衣服的磨损]。[画幅比例]。
要诚实、不摆拍：保留真实皮肤和日常细节。不要美化，不要重度修图，不要磨皮，不要戏剧化的调色，画面里不要有文字和水印。
```

这就是林栖定妆照用的写法，效果已经验证过。

### 模板 B2：专业纪实风景 / 旅行

```
一张真实照片，像纪录片摄影师在[地点]随手拍下的一帧，不是宣传照，不是明信片。
[景别和机位，例如「平视，35mm，站在木栈道上」]，画面里有[主体]，还有[一两样真实的杂物或人迹：栈道栏杆、远处的游客、泥地上的脚印]。
光：[时间和天气，例如「上午，云很多，一片云影正落在草甸上」]；[允许一处不完美：雪的高光略过曝 / 天空有一点灰]。
颜色克制，饱和度低于宣传照，有细颗粒。画面里不要有文字和水印。
```

### 模板 C：修改（一次只改一处）

```
保持这张照片里的[人物的脸 / 构图 / 光线 / 其他一切]完全不变，只把[一处具体的地方]改成[……]。不要改动其他任何东西，不要美化。
```

## 四、各家工具的补充

- **GPT（ChatGPT 生图）**：官方写法是写「真实照片 / photorealistic」，写皮肤纹理，写「抓拍、不摆拍、不要美化、不要重度修图」；人像近景可以比较 medium 和 high 两档质量（OpenAI cookbook）。A1 那段提示词最早就是在 GPT-4o 上火起来的，后来在 GPT Image 2 上有人复现过。
- **Gemini（Nano Banana）**：官方模板就是 B1 的三段式（镜头和主体 → 光和气氛 → 镜头参数和纹理 → 画幅）。社区建议偶尔不写「photorealistic」，改写具体相机或胶片，能减少塑料感（社区经验，未验证）。
- **Midjourney**：加 `--style raw`，`--s` 调低（社区常用 20–50）。raw 会减少 Midjourney 自己的审美加工。
- **FLUX**：社区流行「文件名技巧」：在提示词里写 `IMG_1025.HEIC` 这类相机文件名，会出手机快照的感觉；写「candid」「amateur」能减轻塑料皮肤。这些是 2024 年的社区经验，换了新模型未必有效（未验证）。

## 五、挑图：看这些地方

1. **影子**：同一个太阳下，所有影子方向一致（Farid）。
2. **反射**：镜子、水面、玻璃里的东西对得上。
3. **透视**：地砖、栏杆、建筑的线条该汇聚到同一个消失点。
4. **手和文字**：手指数目、招牌上的字。
5. **皮肤和眼神**：有毛孔；两只眼睛里的反光来自同一个光源。
6. **重复纹理**：背景里同样的叶子、砖块、人脸在重复。
7. **太完美**：构图太正、颜色太艳、人太好看，反而要警惕。

## 六、边界

- 不用真人（明星、熟人）的脸：肖像权的风险，见第二主角文件里的法律说明。
- 这类以假乱真的图片已经引起担忧；OpenAI 会给生成图加 C2PA 元数据（爱范儿）。我们发布时照常标注「AI 生成」。
