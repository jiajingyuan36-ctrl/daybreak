# 03 · 内容地图与两周排期

> 原则：知识与陪伴为主，不做“替你算”。每条都能用网站的一个页面承接（链接只放主页简介，正文不贴链接，见 待确认.md）。
> 选题里的星座、牌、日期全部来自网站数据（`src/zodiac.ts`、`src/plain.ts`），不另编。

## 方向 A · 星座 × 塔罗：你的星座在韦特塔罗里是哪几张牌

**为什么**：白羊座那条已经开了头；可以排成十二期的系列；知识型、风险低；网站星座页逐个承接。
**承接页**：`/zodiac/`（每个星座都有锚点，如 `/zodiac/#taurus`）

| 选题 | 切入角度 |
| --- | --- |
| A1 金牛座的五张牌（教皇、皇后、星币五六七） | ① 系列第二期，“上回讲了白羊”；② 金星守护 + 月亮入旺：为什么金牛这么在意舒服；③ 星币五到七：从“缺”到“攒”到“等”，正好是金牛的节奏 |
| A2 天蝎座 = 死神牌？（当季：2026 年 10/23 – 11/22） | ① 辟谣：死神牌不是死亡，画面里太阳在升起；② 天蝎季的提醒：适合给一件事画句号；③ 圣杯五六七：失落、怀旧、幻想——天蝎的情绪三段 |
| A3 射手座的五张牌（节制、命运之轮、权杖八九十）（2026 年 11/22 下午起） | ① 为什么爱自由的射手，对应的却是“节制”；② 木星守护 = 命运之轮；③ 权杖八九十：冲、守、扛 |
| A4 十二星座对应的大牌一张图 | ① 收藏型清单；② “找找你的牌”互动；③ 金色黎明会是谁（Waite 和画师都在里面） |
| A5 守护星是什么 | ① 七颗古典行星各对应一张大牌；② 为什么没有天王星海王星（古典体系只有七颗）；③ 火星守护的白羊和天蝎为什么都有“高塔” |
| A6 元素与性质：火象基本星座是什么意思 | ① 托勒密怎么说；② 用季节解释（基本 = 季节开始）；③ 你是哪种 |
| A7 两个人的星座 | ① 白羊 × 天蝎：同为火星守护；② 相位怎么看；③ 引到 `/pair/` |

## 方向 B · 早上一张牌：开启一天的小仪式

**为什么**：这是晨启和其他塔罗号最不一样的地方；能做成固定栏目；每天都有素材。
**承接页**：`/ritual/`

| 选题 | 切入角度 |
| --- | --- |
| B1 我每天早上起床第一件事：抽一张牌 | ① 仪式的步骤（深呼吸、选心情、洗牌、切牌、选一张）；② 为什么是早上不是睡前；③ 一分钟就够 |
| B2 今天的牌：星星 | ① “风波过后慢慢恢复”；② 今天可做：写下一件比昨天顺利一点点的事；③ 逆位：泄气的时候找小变化 |
| B3 抽到不喜欢的牌怎么办 | ① 网站每天可以换三次，但不换也行；② “不好”的牌其实在提醒什么；③ 把它当作今天要留意的一件事 |
| B4 晚上回头看早上那张牌 | ① 早晚两个触点；② 晚间回顾的问题；③ 一周后的回望 |
| B5 心情不同，读同一张牌 | ① 疲惫时读皇帝；② 焦虑时读命运之轮；③ “你选了什么心情” |
| B6 一周七张牌的手帐 | ① 截图拼图；② 哪张出现了两次；③ 收藏型 |

## 方向 C · 看懂一张牌：1909 年原版画面里的细节

**为什么**：审美和知识是晨启的强项（原版彩色扫描、Waite 原文）；收藏率高；完全不涉及“预测”。
**承接页**：`/encyclopedia/`

| 选题 | 切入角度 |
| --- | --- |
| C1 愚人：塔罗的第一张牌 | ① 崖边、小包、小狗：每样东西的意思；② 编号 0，“还没开始”；③ 今天可做：换一条路去买咖啡 |
| C2 死神牌里的太阳 | ① 远方两座塔之间太阳在升起；② 为什么是骑白马；③ 和 A2 配合发 |
| C3 1909 年的原版牌长什么样 | ① 画师 Pamela Colman Smith；② 为什么网站坚持用原版扫描；③ 和现代牌的颜色对比 |
| C4 正位和逆位到底差在哪 | ① 逆位不是“坏”，是“卡住了”；② 同一张牌正逆两段对照；③ 选一张牌你会怎么读 |
| C5 命运之轮上爬和滑的动物 | ① 起落都正常；② 能管的和管不了的；③ 收藏 |

## 方向 D · 状态陪伴：今天有点累的时候

**为什么**：回应小红书上最大的情绪需求（焦虑、疲惫），但用“陪伴 + 一件小事”的方式，不用“预测 + 恐吓”。
**承接页**：`/ritual/`（心情选项）

| 选题 | 切入角度 |
| --- | --- |
| D1 最近很累的人，可以读读这三张牌 | ① 星星、节制、权杖十：各一句话；② 各一件十分钟小事；③ “你今天选了什么心情” |
| D2 焦虑的早上，给自己的一句话 | ① 命运之轮逆位：能管的和管不了的；② 写两栏；③ 不替代专业帮助的提醒 |
| D3 不想开始的周一 | ① 愚人逆位：慢半拍出发也来得及；② 只做第一步；③ 周一固定栏目 |
| D4 告别一件事 | ① 死神正位：给不合适的事画句号；② 删掉一项待办；③ 配合天蝎季 |
| D5 给考试周的你 | ① 皇帝正位：写下开始和收工时间；② 不说“考试运”；③ 学生用户（待Leo确认） |
