# 视频提示词：先设计镜头，再写字

本技能来自本项目 8 个 AI 视频项目的成败，以及 OpenAI、Google、可灵、海螺的官方指南。规则都标了证据范围。**不要把单个案例推成通用规则**：这是本项目最常犯的错（见 references/failure-log.md）。

## 一、动笔前先回答这五个问题

1. **用的是哪个模型，它是会自己扩写的智能体（Muse、Gemini 里的 Veo），还是照字面执行的模型？** 见 references/models.md。
2. **要的是「控制和一致」还是「好看和惊喜」？** OpenAI 官方的说法：详细提示词换来控制和一致，短提示词换来创意空间，两者都对。多镜头要前后一致、要和剪辑对位，就写详细；单个镜头要出彩，就先写短的，或者写详细但只锁关键处。
3. **观众第一眼看到什么、最后停在哪一帧？** 写不出来，就说明镜头还没想清楚。
4. **光从哪里来、阴影落在哪里？** 只有一个主光源，曝光说得通。见 references/light-design.md。**这一条决定了真假。**
5. **镜头为什么动？** 运镜要有动机：人走，镜头就退；人停，镜头就停。一个镜头只有一个主运镜、一个主动作。见 references/camera-moves.md。

## 二、写

- 开头先定风格和规格：时长、画幅（「in exactly 16:9 aspect ratio」或中文「横屏 16:9」）、一镜到底、纪实还是剧情。官方说法：风格是最强的杠杆，要放在前面。
- 场景：只写看得见的东西。不写「美丽的街道」，写「湿沥青、斑马线、水洼里的霓虹倒影」。
- 时间轴按秒写节拍：「0–3 秒……3–7 秒……7–10 秒……」。动作写成可数的步骤：「走四步到窗边，停一下，最后一秒拉开窗帘」。
- 光：写光源、方向、软硬，加 3–5 个颜色锚点。
- 声音：写同期声和拟音；不要音乐就写「没有配乐」。
- 负面限制**只管质量，不管内容**：「严禁磨皮、廉价 HDR、影棚光、过饱和、画面中出现文字」可以写；不要列具体的表情和动作（列了「不要大哭、不要皱眉」反而会被做出来）。
- 图生视频：文字只写怎么动，不重述图里已有的人、衣服、场景（Google 和 OpenAI 都这样说）。
- 中文和英文都能写；Muse 用中文的效果见 references/examples.md 的 Gemini 案例。

## 三、交出去之前自查

按 references/realism.md 的「假的来源」表逐条过一遍：
- 光源有几个？
- 天空和逆光下的脸是不是同时曝光刚好？
- 运镜有没有动机？
- 动作是不是套路（仰望、回眸、流泪）？
- 有没有写数字、品牌、文字，而画面里正好有能写字的表面？

## 四、生成之后

- 同一个提示词出 2–4 条再挑：每次结果都不一样，这是正常的（OpenAI 官方说法）。
- 逐条检查：分辨率和比例；逐秒抽帧看脸、手、光；用程序检测片子中间有没有切镜；放大看画面里有没有字。
- 改的时候一次只改一处，并说清改什么：「同一个镜头，只换成 85mm」。屡次失败就减法：机位固定、动作简化、背景清空，跑通了再加。
- 每个结果写进 references/failure-log.md 或 references/examples.md：哪一条写法起作用，哪一条没用。**结论要有对照，没有对照就标「推测」。**
