# 运镜：动机、写法和风险

原则：**一个镜头一个主运镜、一个主动作**（OpenAI 官方、可灵、Seedance 社区指南一致）。运镜要有动机，镜头的动作和人的动作是一体的。

## 有动机的组合（推荐）

| 组合 | 写法 | 证据 |
|---|---|---|
| 人朝镜头走，镜头后退 | 「她迎着镜头缓步走来，镜头保持距离平稳后退」 | Gemini 西藏：Muse 改成了从手往上摇到脸再绕到背后，但整体成立 |
| 由细到全的揭示 | 「从双手的微距特写开始，向后拉开、上摇到中近景，最后焦点移到背景」 | Gemini 西藏；社区教程也常用 |
| 跟拍 | 「手持，在她身后两米跟着走，有自然的轻微晃动」 | 西藏第二版：像真的，但平 |
| 固定机位，人和光在动 | 「三脚架，镜头完全不动」 | 珠峰 E、F，泰坦尼克 16、17：最稳 |
| 横移看风景 | 「极慢的横向移动，从左到右」 | 珠峰 A、G：稳 |
| 航拍前进（风景） | 「低空缓慢向前滑行」 | 珠峰 C、I：可以；有人物时不行 |

## 有风险的写法

| 写法 | 问题 | 证据 |
|---|---|---|
| 推近（push in），即使写「几乎察觉不到」 | Muse 会推得比要求大很多 | 珠峰 B、D；西藏 A-4 从半身推到大特写 |
| 绕静止的人环绕 + 推近 + 换焦 | 动机不足，被做成套路大片 | 西藏 A-4；社区教程说纯文字做「转头 + 环绕」容易失败 |
| 沿整条大物体飞越 | 前 5 秒可以，后面物体变形 | 泰坦尼克 04 |
| 一个镜头里又近景又航拍又切室外 | 等于要求剪辑，模型会乱切 | NodeLoc 50 条 |

## 写法细节

- 景别和机位写在前：「中近景，平视」「微距特写」「低机位」。没写景别，模型默认拍中景（Sora 指南的第三方总结）。
- 焦段一句话就带出景深和透视：「35mm」「50mm 浅景深」「85mm」。
- 手持感要写「轻微、自然的呼吸感」，写重了会晃。
- 换焦（rack focus）写清从哪到哪、第几秒：「7–10 秒焦点从她的背影移到后方的墙和经幡」。
- 「一镜到底」要写，但挡不住 Muse 中途切镜（泰坦尼克 02、03、17），交回后要检测。
- 方向写死：「从画面左边出画」「朝画面右侧」，不写「沿着」「走向远方」。
