# 写实照片 / 定妆照（视频首帧的来源）

完整调研和模板见 content-kit/写实照片提示词模板.md（视频工作分支）。要点：

- **两条路先选一条**：A 随手拍（手机、卡片机、朋友抓拍）最容易以假乱真；B 专业纪实（好相机、讲究光）更难，要靠光和细节。视频首帧多半走 B。
- **真实感的六个来源**：
  1. 说明设备和媒介（iPhone、CCD 卡片机加闪光灯、35mm 胶片）
  2. 写不完美（轻微运动模糊、局部过曝、角度歪）
  3. 写普通（杂物、路人、主体不居中）
  4. 光要有来源，物理要对（影子方向一致、反射对得上）
  5. 人要具体（不写就撞成「平均脸」）
  6. 删掉美化词，写上「不美化、不修图」
- **出处**：
  - Reddit 爆款原文 An extremely unremarkable iPhone photo…（GPT-4o 时期；爱范儿实测和真照片难分）
  - Google 官方三段式：镜头 + 主体 → 光 + 气氛 → 镜头参数 + 纹理 + 画幅
  - OpenAI 官方：photorealistic + 真实皮肤 + 抓拍不摆拍 + no glamorization, no heavy retouching
- **工具参数**：
  - Midjourney：`--style raw --s 20–50`
  - FLUX：文件名技巧 `IMG_1025.HEIC`，或写 candid、amateur（社区经验，未验证）
- **挑图看**：影子方向、反射、透视消失点、手和文字、两眼反光是否同源、背景纹理重复、是否「太完美」（Hany Farid 的鉴别方法）。
- **已验证**：林栖定妆照（B 路线：专业纪实人像，光从右前方来，抓拍，不美化）。
- **边界**：不用真人的脸（《民法典》第 1019 条）；发布时标注 AI 生成。
