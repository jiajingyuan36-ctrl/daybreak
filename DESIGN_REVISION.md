# DAYBREAK design revision
Reference screenshot labels Kozuka; no font file or licensed Adobe web project was supplied. Actual deployed typeface: locally hosted Source Han Sans CN, SIL OFL (license shipped). This is a visual alternative, not Kozuka. Display 300, body400, selected labels500/600. One global --font-ui variable, including forms and canvas exports. SVG artwork carries no font-dependent text.

Shared site chrome includes all six routes, active state and dark/light/automatic theme. Legacy persisted daily draws/reviews remain untouched. Calendar no longer displays the deterministic energy scores; the engine retains old return fields for compatibility only. Sensory notes and sources collapse by default. Daily draw uses actual card meaning, one action and one review prompt; detail interpretations collapse. RWS symbols explicitly describe historical imagery, not the original geometric artwork. Court cards have a framed upper emblem, numeric minors grouped suit marks, majors independent emblems.

Kozuka can replace the global face once a valid web license and files or authorized Adobe embed project are supplied. No paid font or AI service was added.
